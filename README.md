# CRUD Sistem Tugas Akhir Mahasiswa dengan Laravel

## Deskripsi
Repo ini merupakan implementasi CRUD (Create, Read, Update, Delete) di Laravel yang sebelumnya masih menggunakan PHP Native.

## Petunjuk Pemeriksaan

Berikut bagian-bagian proyek yang dapat diperiksa:

### 1. Model
**Lokasi:** `app/Models/Mahasiswa.php`

### 2. Migration
**Lokasi:** `database/migrations/`

### 3. Controller
**Lokasi:** `app/Http/Controllers/MahasiswaController.php`

### 4. Routes
**Lokasi:** `routes/web.php`

### 5. View
**Lokasi:** `resources/views/`
